# 마시떡 홈페이지 🍡

용인 마시떡의 새로운 홈페이지입니다. 전통과 현대가 만나는 프리미엄 떡집의 브랜드 아이덴티티를 반영한 모던하고 반응형 웹사이트입니다.

## 🌟 프로젝트 개요

- **브랜드**: 마시떡 (味始餅)
- **업종**: 전통 떡 제조 및 판매
- **위치**: 경기도 용인시
- **운영 기간**: 10여년
- **목표**: 현대적 감각의 브랜드 이미지 구축 및 온라인 마케팅 강화

## ✨ 주요 기능

### 1. 헤더 (Header)
- 고정 헤더 (Sticky Header)
- 브랜드 로고 및 슬로건
- 메인 내비게이션 메뉴
- 검색 및 장바구니 기능
- 반응형 모바일 메뉴

### 2. 히어로 섹션 (Hero Section)
- 강력한 첫인상과 브랜드 메시지
- CTA 버튼 (제품 보러가기, 브랜드 스토리)
- 그라데이션 배경과 텍스처

### 3. 브랜드 스토리 (Brand Story)
- 마시떡의 철학과 가치
- 전통의 재해석, 건강한 재료, 장인의 정성
- 스크롤 애니메이션 효과

### 4. 제품 쇼케이스 (Products)
- 카테고리별 제품 필터링
- 제품 카드 호버 효과
- 가격 및 구매 버튼
- 반응형 그리드 레이아웃



### 6. 구매후기 (Reviews)
- 실제 고객 경험 공유
- 별점 시스템
- 자동 캐러셀 형식의 리뷰 카드
- 좌우 화살표 네비게이션

### 7. 이벤트 & 공지 (Events)
- 최신 소식 및 프로모션
- 날짜별 이벤트 카드
- 상세 정보 링크

### 8. 고객센터 (Contact)
- 연락처 정보
- 온라인 문의 양식
- 영업시간 및 주소 안내

### 9. 푸터 (Footer)
- 회사 정보 및 링크
- 소셜 미디어 연결
- 이용약관 및 개인정보처리방침

## 🔧 커스터마이징

### 색상 변경
`styles.css` 파일의 CSS 변수를 수정하여 브랜드 컬러를 변경할 수 있습니다:

```css
:root {
    --primary-brown: #4f3a2c;    /* 주조색 */
    --secondary-green: #2d5a3d;  /* 보조색 */
    --accent-ivory: #f8f6f1;     /* 강조색 */
}
```

### 콘텐츠 수정
- **HTML**: `index.html`에서 텍스트 및 구조 수정
- **이미지**: 실제 제품 및 공간 이미지로 교체
- **연락처**: 실제 연락처 정보로 업데이트

### 기능 확장
- **스마트스토어 연동**: 제품 구매 시 스마트스토어로 연결
- **SNS 피드**: 인스타그램 API 연동
- **예약 시스템**: 향후 확장 예정
- **회원 시스템**: 로그인 및 마이페이지
