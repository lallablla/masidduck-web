# 마시떡 홈페이지 사용 가이드

> 사장님을 위한 관리자 사용 설명서입니다.

---

## 관리자 페이지 접속 방법

스마트폰 또는 PC 브라우저에서 아래 주소로 접속하세요.

```
https://masidduck-web.vercel.app/admin
```

비밀번호를 입력하면 관리 화면으로 들어갑니다.

---

## 1. 매일 하는 일

### 아침 — 오늘 팔 떡 켜기

1. `/admin` 접속 후 로그인
2. 오늘 준비한 떡 옆 **토글을 오른쪽으로** 눌러 켜기 (초록색 = 판매 중)
3. 고객용 페이지(`/today`)에 즉시 반영됩니다

여러 개를 켜도 됩니다. 이름 검색창을 활용하면 빠르게 찾을 수 있어요.

### 저녁 (또는 다음날 아침 켜기 전) — 모두 끄기

1. 헤더 오른쪽 **"모두 끄기"** 버튼 클릭
2. 확인 팝업에서 **확인** 누르기
3. 모든 떡이 꺼진 상태로 초기화됩니다

> 매일 새로 켜야 하는 이유: 전날 떡이 다음날에도 표시되는 것을 방지하기 위해서입니다.

---

## 2. 새 떡 추가하는 법

시즌 메뉴, 신제품이 생겼을 때 등록하세요.

1. 관리자 페이지 헤더에서 **"+ 새 떡"** 버튼 클릭
2. 양식 입력:
   - **떡 이름** (필수): 메뉴 이름을 입력하세요
   - **사진** (선택): 📷 버튼을 누르면 카메라 또는 갤러리에서 선택 가능
3. **"추가"** 버튼 클릭

새로 추가된 떡은 **토글이 꺼진 상태**로 등록됩니다. 오늘 팔 떡이라면 추가 후 토글을 켜주세요.

> **사진 팁:** 스마트폰으로 바로 촬영해서 올릴 수 있어요. 사진은 자동으로 최적화되어 업로드됩니다.

---

## 3. 비밀번호를 잊어버렸을 때

비밀번호는 Vercel 환경변수에 저장되어 있습니다. 아래 순서로 변경하세요.

1. [vercel.com](https://vercel.com) 접속 후 로그인
2. **masidduck-web** 프로젝트 클릭
3. 상단 탭에서 **Settings** 클릭
4. 왼쪽 메뉴에서 **Environment Variables** 클릭
5. `ADMIN_PASSWORD` 항목 오른쪽 **점 3개(···)** 클릭 → **Edit**
6. 새 비밀번호 입력 후 **Save**
7. 상단 탭 **Deployments** → 최근 배포 오른쪽 **점 3개** → **Redeploy**

Redeploy가 완료되면(약 1분) 새 비밀번호로 로그인됩니다.

---

## 4. 자주 묻는 문제

### Q. 토글을 켰는데 고객 페이지에 안 보여요

- 브라우저 새로고침(당기기) 해보세요. 고객 페이지는 3분마다 자동 갱신됩니다.
- 인터넷 연결을 확인해주세요.

### Q. 사진이 안 올라가요

- 사진 업로드는 **Vercel Blob** 서비스를 사용합니다. Vercel 대시보드 → **Storage** 탭에서 Blob Store가 연결되어 있는지 확인해주세요.
- 사진 없이 이름만 등록하면 기본 아이콘(🍡)으로 표시됩니다. 나중에 사진을 바꾸려면 개발자에게 문의하세요.

### Q. 로그인이 계속 풀려요

- 로그인 상태는 **7일간** 유지됩니다. 7일이 지나면 다시 로그인해야 합니다.
- 브라우저 데이터(캐시/쿠키)를 삭제한 경우에도 다시 로그인이 필요합니다.

### Q. 페이지가 아예 안 열려요

- Vercel 서비스 상태 확인: [vercel-status.com](https://www.vercel-status.com)
- 잠시 후 다시 시도해주세요.
- 문제가 지속되면 개발자에게 연락해주세요.

### Q. 떡을 잘못 추가했어요, 삭제하고 싶어요

현재 관리자 화면에서는 삭제 기능이 없습니다. 삭제가 필요하면 개발자에게 문의해주세요.
